# Lab07 : Security Fundamentals
## 实验内容
通过 GnuPG（GPG）工具学习对称 / 非对称加密、数字签名、哈希校验，同时掌握 Linux 文件权限管理
### 1. 对称加密（单密钥）
- 原理：加密，解密使用同一个密钥
- 命令：`gpg --symmetric 文件名`（加密）、`gpg --decrypt 加密文件.gpg`（解密）；
- 实验任务：用密码ocfdecal解密file1.txt.gpg，获取明文内容。
### 2. 非对称加密（公钥 + 私钥）
- 原理：公钥公开用于加密，私钥保密用于解密，密钥成对生成；
- 基础命令：生成密钥对`gpg --full-generate-key`、公钥加密`gpg --recipient 接收者 --encrypt 文件名`、私钥解密`gpg --decrypt 加密文件.gpg`；
- 密钥管理：实验要求掌握导入密钥、导出密钥（带 --armor 参数）、查看密钥环的命令；
- 实验任务：用私钥lab7privkey解密file2.txt.gpg，获取明文内容。
### 3. 数字签名
- 原理：私钥签名文件，公钥验证签名，确保文件未被篡改、来源可信；
- 命令：`gpg --sign 文件名`（签名）、`gpg --verify 签名文件.gpg`（验签）。
### 4. 哈希校验（校验和）
- 原理：哈希函数将任意长度文件转为固定长度字符串，用于校验文件完整性；
- 常用命令：`md5sum 文件名`（MD5 哈希）、`sha1sum 文件名`（SHA1 哈希）；
- 实验任务：计算file3.txt的 MD5 值，再计算该 MD5 值的 SHA1 值。
### 5.Linux 文件安全模块
实验需先执行sudo setup.sh初始化环境，核心学习Linux 文件权限三大主体（所有者 / 所属组 / 其他用户）+ 三大权限（读 / 写 / 执行），以及对应管理命令：
- 查看权限：`ls -l`；
- 修改归属：`chown`；
- 修改权限：`chmod`；
- 实验任务：
    - 查看file4.txt权限并解释含义；
    - 给file5添加执行权限并运行，获取输出；
    - 修改file6.txt归属为当前用户；
    - 设置file7.txt仅自己可读；
    - 设置file8.txt仅 root 可读、无人可写；
    - 设置file9.txt仅自己可读、原所有者不可读。
